# Health Data Analysis

## Mål

Målet med projektet är att använda Python för att läsa in, bearbeta och analysera syntetisk patientdata. Projektet undersöker skillnader i glukos- och pulsvärden före och efter medicinering och visar resultaten på ett tydligt sätt med hjälp av grafer.

## Metod

1. Läsa in patientdata från en CSV-fil.
2. Organisera patientdata efter patient-ID.
3. Dela upp mätvärden beroende på om patienten fått medicin eller inte.
4. Beräkna genomsnittliga värden före och efter medicinering.
5. Beräkna skillnaden mellan värdena.
6. Visualisera patientens värden över tid med hjälp av matplotlib.

## Resultat

Programmet kan ta emot ett patient-ID och visar analysen för den valda patienten. Resultatet visar genomsnittliga värden före och efter medicinering samt skillnaden mellan värdena. Programmet visar även en graf som gör det lättare att se förändringen över tid.

## Analys

Projektet visar hur Python kan användas för att strukturera, analysera och visualisera hälsodata. Genom att jämföra värden före och efter medicinering går det att se förändringar i den syntetiska datan.

## Reflektion

Det svåraste i projektet var att organisera patientdata och få analysen att fungera för varje individuell patient. Jag har också fått arbeta med CSV-filer, dictionaries, klasser, arv, felhantering och visualisering med matplotlib. Ett område jag skulle kunna utveckla vidare är att göra programmet mer flexibelt och lägga till fler typer av analyser.
